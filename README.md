# srozfv lab

Демо: [srozfv lab](https://srozfv.github.io/srozfv-lab/).

Рабочее пространство для анализа CSV и TSV. Распакуйте архив и откройте `dist/index.html` в браузере. Установка, аккаунт и соединение с интернетом для локального запуска не нужны. Сразу открывается синтетический набор из 4 800 строк.

## Рабочий сценарий

1. **Обзор.** Посмотрите размер таблицы, пустые ячейки, дубликаты и динамику на ISO-датах.
2. **Качество данных.** Проверьте типы, уникальные значения, долю пропусков и частые значения. Ищите и сортируйте строки, комбинируйте фильтры и выгружайте профиль или текущую выборку.
3. **Срезы.** Выберите до двух полей группировки и агрегацию. Поддерживаются количество строк, сумма, среднее, минимум и максимум. Выгружается весь результат, даже если на экране только одна страница.
4. **A/B-тесты.** Назначьте столбцы ID, группы, основной и защитной метрик. Задайте ожидаемую пропорцию, минимальный эффект и допустимый рост риска. Приложение проверит SRM, рассчитает доверительные интервалы и предложит действие по заданным правилам. Итог и настройки экспортируются в JSON.

## Форматы и границы расчёта

- До 20 МБ, 100 000 строк и 100 столбцов. Первая строка содержит уникальные заголовки. Поддерживаются UTF-8, Windows-1251, запятая, точка с запятой и табуляция.
- Числа могут использовать десятичную точку или запятую. В числовых агрегациях пропуски и нечисловые записи исключаются. Группа без числовых значений получает пустой результат. Код вроде `001` остаётся текстом.
- Фильтры между собой объединяются через И и действуют на таблицу просмотров и срезы. Поиск работает только в таблице строк. Обзор и профиль описывают исходный файл.
- A/B принимает одну строку на единицу рандомизации. Метрики задаются строго как 0 или 1; наблюдения с неполным окном надо исключить до импорта. Сравнение не использует фильтры из срезов. Защитная метрика трактуется как риск, для которого рост нежелателен. Используются интервал Ньюкомба на основе Уилсона и χ² для SRM при пороге 0,001. Инструмент не рассчитывает мощность и не корректирует повторные просмотры результатов.
- Файл остаётся в памяти вкладки. Обновление страницы восстанавливает демоданные. CSV экспортируется с BOM для совместимости с Excel, с разделителем «;» и нейтрализацией ячеек, похожих на формулы.

## Проверки

~~~sh
node --test
~~~

Проверки охватывают CSV с кавычками и переводами строк, TSV, ошибочные файлы, профиль, фильтры, агрегации, валидацию A/B, контроль дисбаланса и защиту CSV-экспорта. Код приложения в `dist/`, сторонние библиотеки в браузере не загружаются.
